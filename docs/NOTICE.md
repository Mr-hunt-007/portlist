# Third-party marks on this site

`docs/index.html` draws six brand marks: Claude, OpenAI, Google Gemini, GitHub
Copilot, GitHub and Buy Me a Coffee. The path data is from
[simple-icons](https://github.com/simple-icons/simple-icons), which releases the
SVGs under **CC0-1.0**.

CC0 covers the drawing, not the trademark. The marks belong to their owners and
are used here **nominatively**: to name the tools portlist reads from and the
services this project is hosted on. They are not part of portlist's own logo,
they do not appear in its icon or wordmark, and none of those companies endorses
or is affiliated with this project.

Cursor and VS Code are named in text rather than drawn, because the icon set
carries no mark for them and an approximation would be worse than a word.

`plate-observatory.png` is artwork supplied by the project owner. Everything
else in `docs/` is generated by the scripts in `tools/`.

## Logos in the living harbour

The original brand-mark paths in `plcore/data/world.html` came from
[Simple Icons](https://simpleicons.org) 16.32.0. The added Traefik Proxy,
Pi-hole, OpenCode, Unity and Supabase paths came from Simple Icons `develop`
commit `d0b3c2d7153794b912913746fc0498a5d3211727` (2026-09-25). Simple
Icons releases these SVG paths under CC0 1.0; generic harbour emblems are
drawn by this project instead. CC0 for the artwork does not grant trademark
rights. The brand marks identify software where there is evidence, not an
endorsement or affiliation by their owners.
