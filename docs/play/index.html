Pick a machine

Each one is a simulated computer, built by portlist's own code from made-up data. Switching starts it fresh.

Install portlist

A Python program with no dependencies, for macOS, Linux and Windows. Click a command to copy it.

macOS and Linux, Homebrew

brew tap Mr-hunt-007/portlist https://github.com/Mr-hunt-007/homebrew-portlist && brew install portlistCOPY

Anywhere, pipx

pipx install git+https://github.com/Mr-hunt-007/portlistCOPY

macOS and Linux, install script

curl -fsSL https://mr-hunt-007.github.io/portlist/install.sh | shCOPY

Then portlist for the views, portlist 3000 to explain one port, or portlist --world for the harbour.
