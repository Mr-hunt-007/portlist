01

The score is itemised

71 High is never a bare number. Every point that made it is listed underneath, so the score can be argued with rather than believed.

02

Unknown origin is counted

Services already listening before portlist first looked get their own number. None of them quietly inherits a repository label from whatever owns the port now.

03

"No answer" is not "zero"

When the container engine does not respond, the card says the count is unknown. A silent zero would be the same sentence as "there are none".

The problem

A port list is not the answer. It is the question.

Three real situations, none of which a port number can settle on its own.

01

Address already in use

Something holds :3000 and you did not start it. Was it this morning's agent session, a container, or a dev server from last Tuesday that never died?

02

An agent left the lights on

Coding agents start servers and move on. The session exits, the server does not, and nothing on the machine remembers which session it belonged to.

03

Bound to the world by accident

0.0.0.0 in a config file is a claim, not a fact. The only honest answer comes from connecting to this machine's real address and seeing what answers.

Install

No strings attached.

One program, no dependencies, nothing system-wide unless your package manager puts it there. Uninstalling leaves one directory you can delete.

# macOS and Linux
$ brew tap Mr-hunt-007/portlist https://github.com/Mr-hunt-007/homebrew-portlist
$ brew install portlist
$ portlist

Installs with its own Python. brew upgrade portlist updates it.

# Windows
> winget install Mr-hunt-007.portlist

Windows needs one thing the others do not: CPython ships there without curses, which portlist is built on. Add pip install windows-curses, or use pipx below, which brings it along on its own.

# anywhere, and the simplest route on Windows
$ pipx install portlist

An isolated environment per tool, and windows-curses is declared as a dependency there, so Windows needs no extra step.

# into ~/.local, no root, nothing system-wide
$ curl -fsSL https://mr-hunt-007.github.io/portlist/install.sh | sh

Piping a script into a shell deserves suspicion, so read it first: it fetches one tarball and writes to two directories. Remove it with rm -rf ~/.local/lib/portlist ~/.local/bin/portlist.

# no build step, nothing to compile
$ git clone https://github.com/Mr-hunt-007/portlist
$ cd portlist
$ python3 portlist.py

The standard library is the whole dependency list. python3 -m plcore works too.

Nothing moves unless it was measured

A dot pulses because that service was measured busy inside the last minute. A particle crosses an edge because a loopback connection between those two ports was observed. A service is marked NEW because it really started listening while you were watching, and the first frame marks nothing at all, because everything is new to the screen and none of it is new to the machine. Inventing motion would make the prettiest part of the program the one lying to you.

Five themes, four speeds

observatory, neon, terminal, aurora, minimal. Static through cinematic. t and s cycle them, n jumps a scene, and the choice is remembered. Turning animation off also stops vibe mode arriving by itself, because asking for a still screen and being given a moving one is not a feature.

Architecture

One scan, one model, eight views.

A view is a question asked of the model, never a second trip to the machine. That is why switching views is instant, why the tab counts always agree with the rows underneath, and why a new view costs a filter rather than a collector.

What it will not do

The restraint is the feature.

  • It never stops anything. The detail pane prints the command and you run it. A tool that both guesses which process is abandoned and can end it will eventually end the wrong one.
  • It opens no listening socket. It connects outward to see what answers, and binds a candidate port for a moment to check it is free. Neither calls listen(), so a tool for watching what is listening never adds to the list.
  • It sends nothing anywhere. No server, no telemetry, no update check. Agent transcripts are read locally and stay there.
  • It says "unknown" out loud. A process that was already running before portlist ever ran has unknown origin, and shows it, rather than inheriting a repository label from whatever owns the port now.
  • It measures instead of assuming. Reachability by connecting, use over time rather than uptime, and a gap in the sparkline where nothing was measured rather than a zero.
