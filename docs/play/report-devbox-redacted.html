How this was measured
  • Reachable: portlist connected to each port from this machine's own network addresses. That proves the local network can reach it; it is not a scan from the internet, and it says nothing about a router forwarding ports.
  • Started by: the process ancestry and environment variable names (never their values), recorded the first time portlist saw the service.
  • Left over: a guess from measured use, age and whether its starter is still running, with the reasons listed. Portlist never stops anything on the strength of it.
  • Risk: a score over the reasons shown with each service, which are the part to read.
  • Redacted: host and user names, addresses, project names, paths and command lines were removed.
